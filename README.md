# Invitación sorpresa · Edward 30

Sitio estático de la celebración sorpresa de Edward.

- **Fecha:** sábado 9 de enero de 2027
- **Citación:** 5:20 p. m. (Edward llega a las 6:00 p. m.)
- **Lugar:** Salón Social, Conjunto Tacuará, Dosquebradas, Risaralda
- **Estilo:** elegante, negro y dorado

## Publicación
Este repositorio usa GitHub Actions para publicar el contenido de la raíz mediante GitHub Pages. La dirección esperada es:

https://0mona15.github.io/30-osito/

## Invitaciones personalizadas
Añade el nombre al enlace con el parámetro `?invitado=`, por ejemplo:
`https://0mona15.github.io/30-osito/?invitado=Julio`

## Pendiente
La página visual inicial no envía todavía confirmaciones. Para activar RSVP y el panel privado hace falta crear la hoja de Google Sheets, desplegar los proyectos Apps Script y configurar sus URL/correo. No publiques datos personales ni listas de invitados en este repositorio público.
